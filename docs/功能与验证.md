# 功能与验证范围

本项目当前适配 SQ9650 与 ZS800J 两种协议。下表表示代码提供的能力，不代表每个开关、档位、固件批次均已实机验收。

## 设置实体

| 型号 | 设置 | 可选值 |
| --- | --- | --- |
| SQ9650 | 夜灯、光感夜灯、自动冲刷、关盖冲厕、脚感控制、预湿润、落座发泡 | 开 / 关 |
| SQ9650 | 座温 | 常温 / 中温 / 高温 |
| ZS800J | 智能夜灯、氛围灯、自动冲刷、关盖冲厕、自动翻盖、自动小冲、脚感控制、水路 UV 杀菌、预湿润、落座发泡、四季温感 | 开 / 关 |
| ZS800J | 座温、水温 | 常温 / 最低 / 偏低 / 标准 / 偏高 / 最高 |
| ZS800J | 风温 | 常温 / 偏低 / 标准 / 偏高 / 最高 |
| ZS800J | 风速 | 1–5 档 |
| ZS800J | 翻盖模式 | 短距档 / 灵敏档 |
| ZS800J | 刷圈发泡 | 快速档 / 中速档 / 标准档 |
| 两种型号 | 释放蓝牙给小程序 | 开：释放；关：恢复连接 |

SQ9650 不提供水温、风温实体。档位名称来自对应界面与协议映射，不将其换算为未经测量的摄氏温度。设置风温、风速不会启动烘干；本版不提供人体清洗或烘干启动操作。

### 设置之间的约束

- SQ9650 开启光感夜灯时，需要先关闭光感夜灯才能直接设置普通夜灯。
- ZS800J「预湿润」关闭时，实测「落座发泡」也关闭；开启预湿润也观察到落座发泡联动开启。本集成允许这一明确联动，不忽略其他设置意外变化。
- ZS800J「四季温感」在协议中是切换命令。程序先读取当前值，相同则不写，写后核对，不自动重放该命令。不同固件下它与手动温度的长期关系仍需验证。
- 当前设置写入采用保守空闲检查：着座、动作执行中或报告故障时可能拒绝写入，不会等待到无人后悄悄执行。

## 动作和状态

两种型号均有开盖、关盖、翻起座圈、放下座圈、大冲、小冲、魔力泡。SQ9650 另有待机；ZS800J 另有自清洁模式、喷嘴清洁、更换喷嘴、停止清洁 / 维护。

动作成功反馈的含义并不完全相同：开合盖圈检查目标位置与运动停止；冲水、发泡、自清洁检查已进入对应运行状态；喷嘴维护检查对应维护工作状态。**开始运行的确认不代表整个周期已经结束。**

状态实体提供工作状态、盖板状态、座圈状态及着座状态。它们来自轮询，不能视作实时传感器；空闲轮询约 30 秒，活动状态约 5 秒，失败恢复约 10 秒，实际周期受通信耗时影响。

稳定长连接环境下，部分单项灯光设置曾测得约 0.5–1.4 秒，偶发读取重试约 3 秒；这是局部测试记录，不是响应时间保证。扫描、弱信号、重连和米家事件传递会增加耗时。

## 通信处理原则

1. 单台设备按顺序执行；不同设备队列独立。释放请求优先于等待的控制，控制优先于等待的轮询，不中断已经发出的物理动作。
2. 相邻相同且尚未完成的设置请求可合并；开 → 关 → 开仍保留顺序。
3. 先读完整状态再写；设置完成后检查目标与其他字段。部分 ZS800J 只读状态缺少 EA 帧时仍显示已读取字段，但写入要求完整状态。
4. 仅在完整新状态明确表示绝对设置未生效时，允许一次断开重连、重新读取及按需重设。
5. 机械动作、四季温感切换、通信超时或不完整反馈不会自动重复写入。冲水、发泡等另有短时冷却限制。
6. 故障、设备忙、目标不匹配与连接失败会作为不同错误处理，不把每次设置拒绝都显示成整台设备离线。

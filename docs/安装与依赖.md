# 安装与依赖

## 开始前：先确认这五件事

1. **确认铭牌型号**：查看马桶铭牌或九牧小程序设备信息，必须是本版适配的 SQ9650 / ZS800J。
2. **确认 HA 能正常打开**：在浏览器打开自己的 HA 地址并登录。没有安装 HA 的用户，先按 [Home Assistant 官方安装指南](https://www.home-assistant.io/installation/)选择安装方式；本教程从一个可正常使用的 HA 开始。
3. **确认主机有蓝牙**：有 USB 接口不等于有蓝牙。若使用 USB 蓝牙适配器，请先确认它受 Linux / HA 支持。
4. **确认米家网关入口**：在手机米家新建场景的执行动作中，能找到中枢网关的「产生虚拟事件」。仅有普通蓝牙 Mesh 网关不代表具有该入口。
5. **确认连接距离**：第一次安装时尽量将 HA 蓝牙适配器靠近马桶，先验证连接，再调整最终摆放位置。

建议按顺序完成：**HA 蓝牙正常 → 安装九牧智联桥 → HA 直接控制成功 → Xiaomi Home 收到网关事件 → 米家控制成功**。不要同时修改所有环节，否则失败时很难定位。

## 1. 环境和连接方式

参考环境为 HA 2026.10.1、Xiaomi Home v0.5.0、Linux BlueZ 5.66。版本号表示已用于验证的环境，并不代表所有旧版或新版都兼容。HACS 元数据将 HA 2026.10.1 作为最低声明版本；尚未逐版本验证。

HA 主机需要能使用 BLE 适配器。先在 HA「设置 → 设备与服务」确认 Bluetooth 集成正常，再安装九牧集成。蓝牙适配器应靠近马桶；穿墙较多时，先移动主机或使用 USB 延长线调整适配器位置。

- **Linux / NAS 容器**：宿主机运行 BlueZ，HA 容器可访问宿主 D-Bus。
- **虚拟机**：确保蓝牙 USB 设备已直通给运行 HA 的虚拟机，未被宿主占用。
- **HAOS / ESPHome 蓝牙代理**：本项目未完整验收。当前包含本地 Bleak 扫描后备路径，不应把代理支持视为已验证能力。
- **小米中枢网关、中控屏、普通路由器**：本教程不把它们当作马桶的通用 BLE 适配器。

容器挂载参考（仅展示相关选项，沿用你现有安装方式与权限配置）：

```yaml
services:
  homeassistant:
    image: ghcr.io/home-assistant/home-assistant:2026.10.1
    network_mode: host
    volumes:
      - ./config:/config
      - /run/dbus:/run/dbus:ro
    restart: unless-stopped
```

这个片段不负责安装宿主 BlueZ，也不适用于在 macOS Docker Desktop 中直接使用 Mac 蓝牙。容器权限与宿主兼容性请参考 [HA Bluetooth 文档](https://www.home-assistant.io/integrations/bluetooth/)。

## 2. 安装九牧智联桥

### 手动安装

1. 打开 [项目首页](https://github.com/mossbyte888/jomoo-mijia-bridge)，点击绿色 **Code → Download ZIP**，解压到电脑。
   解压目录中应看到 `README.md`、`custom_components`、`docs`、`scripts` 等项目。不要把 ZIP 文件直接放进 HA。
2. 只复制 `custom_components/jomoo_local` 到 HA 配置目录。最终路径应为 `/config/custom_components/jomoo_local/manifest.json`。
3. 重启 Home Assistant。
4. 打开「设置 → 设备与服务 → 添加集成」，搜索「九牧智联桥」。若搜索不到，刷新浏览器后检查 HA 日志。
5. 选择铭牌对应型号，输入蓝牙地址，填写可选名称。
6. 多台马桶分别添加。名称用于展示，MAC 用于确定目标设备。

#### 如何找到 HA 配置目录

| 安装方式 | 操作位置 |
| --- | --- |
| HAOS / 带应用商店的安装 | 用已有的文件编辑器、Studio Code Server 或 Samba 访问 HA 配置目录；这些工具只负责复制文件，选择一种即可 |
| NAS / Docker | 在 NAS 容器管理中查看 HA 容器的卷映射，找到容器 `/config` 对应的宿主目录，再用 NAS 文件管理器复制 |
| 虚拟机 HAOS | 将文件放进虚拟机里的 HA 配置目录，不是放到宿主电脑任意文件夹 |

**HA Container 没有 HAOS 的应用商店，不需要为了本项目另装 File editor 应用。** 直接使用宿主机 / NAS 文件管理即可。已有 HA 配置目录通常包含 `configuration.yaml`。

正确目录结构：

```text
/config/
├── configuration.yaml
└── custom_components/
    └── jomoo_local/
        ├── __init__.py
        ├── manifest.json
        ├── config_flow.py
        └── ...其他集成文件
```

若原来没有 `custom_components`，创建它；若已经有，保留其中其他集成。常见错误是多套一层目录，例如 `/config/custom_components/jomoo-mijia-bridge/custom_components/jomoo_local`，HA 不会按本教程识别。

复制后，在 HA「设置 → 系统」的电源 / 重启入口选择重启 Home Assistant；具体按钮位置随 HA 版本变化。等待页面重新连接后再添加集成。首次进入设备页面应有座温、灯光、释放蓝牙等实体，这才是安装成功的第一项证据。

**不要将其他型号选择为 SQ9650 / ZS800J 试写。** 同名蓝牙广播也不能证明协议兼容。

### 通过 HACS 自定义仓库安装

HACS 不是必需依赖，也不代表本项目已进入 HACS 默认商店。

1. 尚未安装 HACS：可直接用上面的手动安装，也可按 [HACS 官方安装文档](https://www.hacs.xyz/docs/use/download/download/)完成安装。两条路线选一种即可。
2. 打开 HA 侧边栏的 HACS，进入菜单中的「自定义存储库」。不同版本菜单位置可能不同。
3. 仓库填 `https://github.com/mossbyte888/jomoo-mijia-bridge`，类型选择 **Integration / 集成**，添加。
4. 搜索「九牧智联桥」，打开详情并下载。
5. 重启 HA，再到「设置 → 设备与服务 → 添加集成」添加设备。

HACS 下载完成只是安装了文件，还需要重启和添加集成。若 HACS 未识别仓库，可按手动方式安装。

### 升级与移除

升级前备份 HA 配置，替换集成文件并重启，或使用 HACS 更新。移除时先在设备与服务中删除集成条目，确认蓝牙已释放，再删除对应文件夹并重启。不要只删除文件而让旧的已加载连接继续运行。

## 3. 查找自己的蓝牙地址

先退出九牧小程序并断开手机连接。马桶被其他终端连接后，可能停止广播。

可在 HA 的 Bluetooth 广播信息中查看附近设备；Linux 也可用 `bluetoothctl`：

```text
bluetoothctl
scan le
# 查看 JOMOO_SMART_ 开头的设备及其 MAC
scan off
quit
```

部分旧版 BlueZ 使用 `scan on`。结合近距离扫描、小程序设备信息确认地址，不能只凭信号最强就认定是哪台。系统蓝牙设置的“配对失败”并不等于 BLE GATT 连接不可用；本集成不要求先做经典蓝牙配对。

## 4. 首次验证

1. 先添加一台、确认型号与地址正确。
2. 等待实体显示实际状态；温度档位应与小程序一致。
3. 在设备空闲时选一个灯光开关，操作后观察实体读回状态和现场灯光。
4. SQ9650 普通夜灯需要先关闭「光感夜灯」，否则本集成会拒绝直接修改。
5. 验证完成后再接入米家事件，避免同时排查多层链路。

连接阶段可能需要扫描和重连，耗时长于稳定连接下的命令。若要临时使用手机，开启 HA 的「释放蓝牙给小程序」；用完退出小程序、断开手机，再关闭该开关。

## 5. 安装 Xiaomi Home

按 [XiaoMi/ha_xiaomi_home 官方说明](https://github.com/XiaoMi/ha_xiaomi_home)安装并完成小米账号授权，将支持虚拟事件的中枢网关导入 HA。仓库安装和账号授权应遵循上游说明，不需要向本项目提供密码或令牌。

### Xiaomi Home 的安装与检查步骤

1. 在 [官方仓库](https://github.com/XiaoMi/ha_xiaomi_home)查看与你的 HA 版本相符的安装说明。手动方式复制其 `custom_components/xiaomi_home` 文件夹；也可按官方说明使用 HACS 安装。
2. 重启 HA 后，在「设置 → 设备与服务 → 添加集成」搜索 **Xiaomi Home**。
3. 按引导登录你实际使用的米家账号，选择与设备所属家庭相同的区域及家庭。登录密码或授权令牌不要写入本项目配置文件。
4. 在设备选择 / 过滤设置中确保包含 **Xiaomi 中枢网关**。只导入插座、灯具不会产生本教程需要的网关事件实体。
5. 完成后进入 Xiaomi Home 集成的设备列表，打开中枢网关，查看其实体。
6. 若安装的是名称相似的其他小米集成，请先核对仓库来源；本教程的事件实体与字段针对 `XiaoMi/ha_xiaomi_home`，不保证与其他集成相同。

完成时应同时具备两个入口：

- 手机米家：场景动作中能选择「中枢网关 → 产生虚拟事件」。
- HA：中枢网关下存在接收虚拟事件的 **`event.` 实体**。

网关固件、区域和 Xiaomi Home 版本可能影响暴露的实体。若缺少入口，请先按上游说明检查固件、自动化极客版及设备导入设置。随后继续[米家接入](米家接入.md)。

## 依赖说明

运行时由 HA 的 Bluetooth 集成提供蓝牙环境，本组件调用 `bleak`、`bleak-retry-connector` 及 HA 自带的 `voluptuous` 等库。不要在 HA 容器内手工升级这些库，以免与 HA 锁定版本冲突。配置生成工具仅使用 Python 标准库，面板仅使用 HA 原生卡片。
